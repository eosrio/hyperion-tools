# Qualify Wire support against the new testnet launched with Wire contracts

The mandatory 4.5 Wire compatibility target is a new testnet that will be launched with Wire's
contracts. The operator states that the testnet does not yet exist at the time of this decision.

Its selected launch node/protocol build, deployed contract set, and unified extension package
define the acceptance profile. Record exact source revisions, deployed contract WASM/ABI artifacts,
extension/component versions, and network/genesis identity when preparing qualification fixtures.
Use this profile for applicable live-ingestion and historical-replay acceptance.

Exact versions, contract inventory, chain configuration, deployment details, and qualification
scenarios remain open. Previously inspected master/release commits inform the design but have not
automatically become the testnet's compatibility baseline.

The testnet launch, plugin implementation, and qualification remain planned work. This decision
records the acceptance target and does not establish that a network has been deployed or that
Wire support has passed acceptance.
